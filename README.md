# Bioeolica-dev — Plataforma de Engenharia Multi-Agente

Repositório **META** para autogeração de times de engenharia multidisciplinar com laboratório virtual, GitOps e publicação científica.

## Arquitetura

```
Engine KDI/Omnibus v3.0 (DNA invariante, PQMS 9.85)
  │
  ├── Orquestração Multi-Agente (time derivado do contexto)
  ├── Workspace Computacional / Lab Virtual
  ├── Engenharia de Contexto (ontologia + grafo + propagação)
  ├── GitOps Pipeline (.github/workflows/)
  └── Pipeline de Publicação Científica (F10)
```

## Engine

A engine `mech-electro-materials-scientist` (KDI/Omnibus v3.0-unified) é o DNA de cada agente:

- **10 princípios filosóficos** (P1-P10) — M³, revisor hostil, auto-instrução
- **10 domínios de engenharia** — com processo de seleção ilimitado
- **7 métodos numéricos** — FEM, MPM, SPH, DEM, Peridynamics, ROM+PINNs, híbridos
- **9 mandatos** (M1-M9) — Open Source First, VVV, Mapa Único, Segurança
- **Workflow F1-F10** — do contexto à publicação
- **13 métricas de qualidade** — PQMS target 9.5/10
- **WAL Protocol** — logs 5W1H com JSON Schema, rollback, encriptação

## Time

O time NÃO é fixo. É derivado do contexto do problema via processo de seleção de domínios:

1. Analisar o problema (F1)
2. Identificar famílias de domínio (ilimitado)
3. Aplicar M³ em cada família
4. Validar relevância
5. Derivar o time dos domínios confirmados
6. Verificar cobertura
